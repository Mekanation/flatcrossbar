# Changelog

## 1.0.0

First release.

- Controller crossbar flattened into plain horizontal bars: Base, LT, RT and LT+RT,
  plus LB, RB, LT x2 and RT x2 through Steam Input chords. Eight buttons per bar.
- Separate keyboard and controller keybind sets; `auto` follows the game's input style.
- Radial wheel on L3 (bars 6, 7 and 8), with the D-pad paging while it is held and
  an adjustable stick sensitivity (`/fcb wheelsense`).
- Act / Insp / Back / Jump buttons use the game's own icons.
- Cooldowns, charges and loss-of-control shown in combat.
- Bars drag and snap to each other, saved layout shared across characters.
- Steps aside for bag, bank, vendor, mail and game-menu windows.
- Macros "FCB Tab Enemy" and "FCB Tab Friend" created on first login.
